# 임진묵 교사의 도구함 · 글쓰기 허브

로그인 없이 사용하는 정적 웹 도구 모음입니다. 질문을 따라 글을 쓰고, 일기를 로컬 폴더에 보관하고, 말씀을 묵상하거나 PDF 글자 수를 확인할 수 있습니다.

## 실행

Node.js가 설치된 환경에서 다음 명령을 실행합니다. 별도 패키지 설치나 빌드는 필요하지 않습니다.

```sh
node serve.mjs
```

브라우저에서 `http://127.0.0.1:4174`를 엽니다. 서버는 내 컴퓨터에서만 접속할 수 있습니다. 종료는 Ctrl+C입니다.

## 도구와 저장 방식

| 도구 | 경로 | 데이터 보관 |
| --- | --- | --- |
| 생각을 잇는 글쓰기 | `/#/writing` | 같은 주소·브라우저 프로필의 localStorage에 자동 저장, TXT 내려받기 |
| 하루 한 장 · 일기장 | `/diary/index.html` | 사용자가 선택한 로컬 폴더에 저장 버튼으로 저장 |
| 셀라 · 오늘의 말씀 | `/selah/index.html` | 포함된 말씀과 질문을 표시, 개인 기록 저장 없음 |
| PDF 글자 수 세기 | `/pdf/index.html` | 선택한 PDF를 브라우저 메모리에서 분석, 서버 업로드 없음 |

일기장 폴더 저장은 HTTPS 또는 localhost에서 PC용 Chrome·Edge의 폴더 선택과 쓰기 허용이 필요합니다. 기록은 `diary-db.json`, 이전 데이터는 `diary-db.backup.json`에 저장됩니다. 자동 저장이 아니며, 재방문하면 같은 폴더를 연결해야 합니다. 모바일 및 폴더 API 미지원 브라우저에서는 폴더 직접 저장을 지원하지 않습니다.

## 개인정보와 보안

- 이 저장소에는 프로그램과 가상 테스트 데이터만 포함합니다. 실제 글, 일기, PDF, 인증키, 배포 관리 파일은 포함하지 않습니다.
- 입력한 글이나 PDF를 외부 AI·서버·분석 서비스로 보내는 기능은 없습니다. 외부 글꼴 요청도 제거했습니다. 호스팅 업체는 일반 접속 정보를 처리할 수 있습니다.
- 글쓰기 자동 저장은 브라우저 데이터 삭제·주소 변경·비공개 모드 종료 시 사라질 수 있습니다. 중요한 글은 TXT로 보관하세요. TXT는 질문 상태 복원 파일이 아닙니다.
- 일기 파일과 백업은 암호화되지 않은 일반 텍스트입니다. 다른 사용자와 공유하거나 Git에 추가하지 마세요. 삭제한 일기는 다음 저장 전까지 백업에 남을 수 있습니다.
- 공용 PC에서는 사용 후 ‘새 글 쓰기’로 브라우저의 글을 삭제하고 내려받은 파일도 직접 관리하세요. 실제 학생 실명·성적·상담 등 민감정보는 입력하지 마세요.
- 공개 저장소와 웹 도구에는 사용자 인증이 없습니다. 민감정보를 다루는 시스템으로 사용하지 마세요.

공개 준비 검토 범위와 제한은 [SECURITY_REVIEW.md](SECURITY_REVIEW.md)에 기록했습니다.

## 검증

```sh
node --test tests/model.test.mjs tests/storage.test.mjs tests/diary.test.mjs
node --check dist/app.mjs
node --check dist/diary/app.mjs
node --check dist/selah/app.js
```

데이터 복원·저장 실패·손상·탭 충돌과 일기 파일 생성·수정·백업·삭제를 검증합니다. 모의 DOM과 파일 핸들 테스트는 실제 브라우저의 폴더 권한, 모바일, 한국어 입력기 검증을 대신하지 않습니다.

## 배포와 수정

HTTPS 정적 호스팅의 배포 디렉터리를 `dist/`로 지정하세요. 별도 빌드 명령은 없습니다. `dist/model.mjs`의 `programs`에서 허브 카드를 관리하며, 상대 경로를 사용해 하위 경로에 배포할 수 있습니다. 이 저장소 공개와 별개로 웹사이트 배포는 호스팅 설정이 필요합니다.

## 외부 구성요소

PDF.js 4.10.38과 worker·CMaps·표준 글꼴을 로컬에 포함합니다. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)와 각 라이선스를 확인하세요. PDF 분석은 텍스트 추출만 사용하며 PDF JavaScript 실행용 뷰어를 구성하지 않습니다. 스캔 이미지 OCR과 암호 PDF는 지원하지 않습니다.
